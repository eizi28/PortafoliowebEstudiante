# Portafolio Personal

Proyecto de portafolio web personal desarrollado como parte del proceso de formación en desarrollo web. Este sitio tiene como propósito presentar mi perfil profesional, habilidades técnicas y proyectos en desarrollo.

---

## 🚀 Tecnologías Utilizadas

- **HTML5**: Estructura semántica, limpia y accesible.
- **CSS3 (Vanilla)**: Maquetación moderna utilizando variables CSS (`:root`), Flexbox, CSS Grid y Media Queries para un diseño 100% responsivo.
- **Git y GitHub**: Control de versiones y gestión del repositorio.

> **Nota:** El proyecto está construido exclusivamente con tecnologías nativas del navegador, sin dependencias ni frameworks externos (sin Bootstrap, Tailwind o librerías pesadas).

---

## 🎨 Características de Diseño

- **Enfoque Minimalista y Profesional**: Estilo sobrio y limpio, enfocado en la legibilidad y la experiencia de usuario.
- **Paleta de Dos Colores**: 
  - *Color base:* Neutro oscuro / grafito (`#171717`) sobre fondo blanco (`#ffffff`) para textos y bordes.
  - *Color de acento:* Azul sobrio (`#2563eb`) para enlaces, botones y elementos interactivos.
- **Diseño Responsivo**: Adaptado para una visualización óptima en ordenadores de escritorio, tabletas y teléfonos móviles.
- **Navegación Fija**: Barra de navegación superior con enlaces rápidos a cada sección.

---

## 📑 Secciones del Sitio

1. **Inicio (Hero)**: Presentación inicial con llamada a la acción y enlaces rápidos.
2. **Acerca de mí**: Resumen del perfil profesional enfocado en desarrollo frontend, backend y bases de datos.
3. **Habilidades y Tecnologías**: Organización del stack técnico (Frontend, Backend y Bases de Datos relacionales).
4. **Mis Proyectos**: Cuadrícula de proyectos con información descriptiva, categorías y tecnologías asociadas.
5. **Contacto**: Sección directa para comunicación por correo electrónico.

---

## 💻 Visualización Local

Para ver el proyecto en tu navegador:
1. Clona o descarga este repositorio:
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   ```
2. Abre el archivo `index.html` en cualquier navegador web moderno (doble clic o clic derecho > *Abrir con...*).
